# Momo 的小星球

Momo 的个人主页和博客。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `index.html` | 主页（GitHub Pages 打开的就是它） |
| `posts/posts.json` | 文章列表：标题、日期、简介 |
| `posts/*.md` | 每篇文章的内容 |

## 怎么写一篇新文章

**第 1 步：新建文章文件**

在 `posts` 文件夹里新建一个文件，比如 `my-trip.md`。
文件名只用英文小写字母、数字和 `-`，不要用中文或空格。

在里面写内容，不用写标题（标题写在下一步）：

```markdown
今天我去了海边。

## 小标题

- 列表第一项
- 列表第二项

> 这是一段引用

**加粗的字**，*斜体的字*，[一个链接](https://example.com)
```

**第 2 步：把文章加进列表**

打开 `posts/posts.json`，在最前面加一段（注意每段之间用逗号隔开）：

```json
[
  {
    "slug": "my-trip",
    "title": "去海边啦",
    "date": "2026-12-01",
    "summary": "一句话简介，可以不写。"
  },
  {
    "slug": "hello-world",
    ...
  }
]
```

- `slug`：和文件名一样，但不要 `.md`
- `date`：格式是 `年-月-日`
- 文章会自动按日期排序，最新的在最上面

保存、上传到 GitHub，过一两分钟网站就更新了。
